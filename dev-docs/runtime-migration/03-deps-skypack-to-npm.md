## Spec

### Context

`00-assessment.md` section 3.4 lists the skypack-hosted packages and section 10 reports that the spike could only run because they were re-sourced from npm.
Skypack is an unmaintained CDN: it is a single point of failure for `./configure.sh` (it is already unreachable from some networks, including the sandbox this plan was written in) and it cannot be used by a Node bundler.
The same packages exist on npm at the same versions; `zod`, `lodash`, `pdfjs-dist` and `acorn-class-fields` already come from `npm:` through the same import map, so the dev launcher (`package/scripts/common/quarto`), the test runner (`tests/run-tests.sh`), the dependency cache (`package/scripts/vendoring/vendor.sh` runs `deno install --entrypoint ...` for `src/quarto.ts`, `src/vendor_deps.ts`, `tests/test-deps.ts`, `package/scripts/deno_std/deno_std.ts`) and the release bundle (`tools/deno-esbuild-bundle.ts` with `@luca/esbuild-deno-loader`, which already bundles the `npm:` packages above) all handle `npm:` today.

How the import maps work (verified by reading the code):

- `src/import_map.json` is the only map in use.
  The dev launcher passes `--importmap=$QUARTO_SRC_PATH/import_map.json`; `tests/run-tests.sh` passes the same; `quarto run --dev` passes it (`src/core/run/deno.ts:39-43`); `tools/deno-esbuild-bundle.ts` passes it to the esbuild loader.
- `src/dev_import_map.json` is generated by `package/src/common/create-dev-import-map.ts` from `import_map.json` plus a `vendor/import_map.json` that no longer exists (`src/vendor/` has 0 tracked files; vendoring was replaced by the `deno install` cache).
  Nothing calls `create-dev-import-map.ts` and nothing reads `dev_import_map.json` (only an old command line quoted in `tests/README.md:369`).
  It is stale and out of scope here (see Decisions).
- After PR 00b, `deno.lock` is committed and `configure`, `quarto-bld`, the bundle and the dev launcher run with `--frozen`; the dev launcher also passes `--cached-only` (`package/scripts/common/quarto:71`).
  Every import-map edit below is therefore followed by `package/scripts/vendoring/update-lock.sh` (re-vendors `package/dist/bin/deno_cache` and adds the new modules to `deno.lock`), and `deno.lock` is committed with the map.
  Without that step every manual `package/dist/bin/quarto` command fails with `The lockfile is out of date` or `not found in cache`.
- CI's dev-cache key hashes `src/import_map.json` and `deno.lock` (`dev-docs/ci-deno-caching.md`), but `restore-keys` still restores an older superset cache in most jobs; only the `Bundle Test` gate (PR 00b) configures from an empty cache, so it is the job that proves the npm packages download and bundle.
- Skypack outside `src/import_map.json` is not this PR's: `package/scripts/deno_std/deno_std.ts:84` (`juice` from `https://cdn.skypack.dev/juice@10.0.0`), its mirror `src/resources/deno_std/run_import_map.json:38` (`stdlib/juice`) and the 25 skypack entries of `src/resources/deno_std/deno_std.lock` serve the user-script stdlib of `quarto run` (shipped in `share/deno_std/`); PR 35 replaces that stdlib.
  `tests/docs/reveal/actors.js` and `src/resources/tools/ast-tracing/*.js` import from skypack in the browser, not in Deno.
  These are on the Phase 0 exit allow-list in PR 07's last task.
- `dev-docs/add-typescript-dependency.md` is marked "FIXME needs updating"; this PR does not rewrite it but the Decisions section proposes the one-paragraph replacement.

 *
 * Pins the module shapes Quarto relies on for the third-party packages that
 * src/import_map.json resolves to npm (formerly cdn.skypack.dev). Each test

import { unitTest } from "../test.ts";
import { assert, assertEquals } from "../asserts.ts";

// src/core/yaml.ts
import { dump, FAILSAFE_SCHEMA, load, Schema, Type, types } from "yaml";
// src/core/date.ts
import dayjs from "dayjs/dayjs.min.js";
import momentGuess from "moment-guess";
// src/core/ansi-colors.ts
import { AnsiUp } from "ansi_up";
// src/execute/ojs/extract-resources.ts, src/command/dev-call/build-artifacts/cmd.ts

// src/execute/ojs/ojs-tools.ts

// tests/unit/binary-search.test.ts

// src/core/hash.ts
import blueimpMd5 from "blueimpMd5";
// src/execute/ojs/compile.ts
import { parseModule } from "observablehq/parser";
// tests/verify.ts
import { parseXmlDocument } from "slimdom";
import xpath from "fontoxpath";
// src/core/sass/add-css-vars.ts
import { parse as parseScss } from "scss-parser";

// deno-lint-ignore require-await
unitTest("npm interop - js-yaml named exports", async () => {
  assertEquals(load("a: 1"), { a: 1 });
  assertEquals(dump({ a: 1 }), "a: 1\n");
  assert(typeof Schema === "function" && typeof Type === "function");
  assert(typeof FAILSAFE_SCHEMA === "object" && typeof types === "object");
  assert(typeof types.int === "object", "types.int is a js-yaml Type");
});

// deno-lint-ignore require-await
unitTest("npm interop - dayjs default export is callable", async () => {
  assertEquals(dayjs("2020-01-02").format("YYYY-MM-DD"), "2020-01-02");
  assert(typeof dayjs.extend === "function");
});

// deno-lint-ignore require-await
unitTest("npm interop - moment-guess default export guesses a format", async () => {
  assertEquals(momentGuess("2020-01-02"), "YYYY-MM-DD");
});

// deno-lint-ignore require-await
unitTest("npm interop - ansi_up named class export", async () => {
  const a = new AnsiUp();
  a.use_classes = true;
  // bold is emitted as an inline style even with use_classes; ansi-colors.ts strips it afterwards
  assertEquals(a.ansi_to_html("\x1b[1mx\x1b[0m"), '<span style="font-weight:bold">x</span>');
});

// deno-lint-ignore require-await
unitTest("npm interop - acorn named exports", async () => {
  const ast = parseES6("const a = 1;", { ecmaVersion: 2020, sourceType: "module" });
  assertEquals(ast.type, "Program");
  assert(typeof Parser.extend === "function");
});

// deno-lint-ignore require-await
unitTest("npm interop - acorn-walk named exports", async () => {
  const ast = parseES6("const a = 1;", { ecmaVersion: 2020, sourceType: "module" });
  let visited = 0;
  simple(ast, { VariableDeclaration: () => visited++ });
  assertEquals(visited, 1);
  assert(typeof make === "function");
});

// deno-lint-ignore require-await
unitTest("npm interop - binary-search-bounds default export", async () => {
  assertEquals(bounds.le([1, 3, 5], 4), 1);
  assertEquals(bounds.ge([1, 3, 5], 4), 2);
});

// deno-lint-ignore require-await
unitTest("npm interop - blueimp-md5 default export", async () => {
  assertEquals(blueimpMd5("a"), "0cc175b9c0f1b6a831c399e269772661");
});

// deno-lint-ignore require-await
unitTest("npm interop - @observablehq/parser named parseModule", async () => {
  const mod = parseModule("x = 1\ny = x + 1");
  assertEquals(mod.cells.length, 2);
  assertEquals(mod.cells[0].id.name, "x");
});

// deno-lint-ignore require-await
unitTest("npm interop - slimdom named parseXmlDocument", async () => {
  const doc = parseXmlDocument("<a><b/></a>");
  assertEquals(doc.documentElement?.nodeName, "a");
});

// deno-lint-ignore require-await
unitTest("npm interop - fontoxpath default export namespace", async () => {
  const doc = parseXmlDocument("<a><b>t</b></a>");
  assertEquals(xpath.evaluateXPathToString("/a/b/text()", doc), "t");
  assertEquals(xpath.evaluateXPathToNodes("//b", doc).length, 1);
});

// deno-lint-ignore require-await
unitTest("npm interop - scss-parser named parse", async () => {
  const ast = parseScss("$a: 1;");
  assertEquals(ast.type, "stylesheet");
});
