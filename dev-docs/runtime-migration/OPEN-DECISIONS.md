To print the rows for one plan, set `NN` to its row id in README "The sequence" (`08`, `14b`, `27b`) and run from the repository root:

```bash
NN=08; f=dev-docs/runtime-migration/OPEN-DECISIONS.md
p="(\bPRs? |\bPRs? [0-9a-z, ]*(, | and ))${NN}\b"
rg -n "^\| [^|]*${p}" "$f"                                       # rows whose first column names the plan
rg -n '^\| Any plan' "$f"                                         # rows for every plan
rg -n '^\| [^|]*(PRs [0-9a-z, ]*[0-9]–[0-9]|Phase [0-9])' "$f"    # rows naming a PR range or a phase: check whether it covers NN
rg -n "$p" "$f" | rg -v "^[0-9]+:\| [^|]*${p}"                    # other rows that mention the plan
```
