# Triage of the Codex review (2026-10-16)

Companion to `REVIEW-2026-10-16.md`. Every finding R01–R21 was re-verified
against the current plan text by four independent read-only passes before
this triage was written. All 21 are accurate on substance. Two nuances:

- R19 copies a bug that `@std/fs` 1.0.16 `copy.ts` has today, so it is not a
  regression versus the Deno build; the plan should still fix it.
- R20 overlooks that `tests/test-deps.ts` already is a locked entrypoint
  (PR 00b lines 35, 121, 225); the real gap is test imports not reachable
  from it, and the Windows `--frozen` fallback.

Line numbers cited by the review all matched the files at HEAD `075cbf4`.

## How the work splits

Three buckets, by what the fix needs rather than by priority:

| Bucket | What it is | Who |
|---|---|---|
| **A. Decide** | A product or contract choice with more than one defensible answer. The plans cannot be corrected until it is taken. | maintainer, with a recommendation below |
| **B. Reconcile** | Cross-plan edits: one rule or table that several plans must agree on, plus the README/HANDOFF/graph refresh. Needs the whole plan set in view. | Fable (one documentation-only pass, the review's step 1) |
| **C. Correct locally** | A defect inside one or two plans with a fix that is already specified. Can run in parallel per plan file once bucket A is decided for the items that depend on it. | Opus, one task per plan file |

Nothing in the review requires running code; every item is a plan edit.
